# Utility Cost Data Validation and Reporting

A small, end-to-end analytics project: check utility invoices against meter readings, flag every data-quality problem, and build a clean reporting table with SQL that a dashboard (for example, Power BI) can use.

It is modeled on the kind of invoice and meter review I did as an Energy Management Analysis Assistant at UNC Greensboro. **All data here is synthetic** (randomly generated by `src/generate_sample_data.py`); no real institution's data is included.

![Average monthly cost per building by utility](output/monthly_cost_trend.png)

## What it does

| Step | Tool | Output |
|---|---|---|
| 1. Load raw invoices and meter readings | Python (Pandas) | |
| 2. Run data-quality checks | Python (Pandas) | `output/exceptions.csv` |
| 3. Load validated rows into a database and summarize | SQL (SQLite) | `output/*.csv` summary tables |
| 4. Plot the monthly cost trend | Matplotlib | `output/monthly_cost_trend.png` |

## Data-quality checks

| Check | Rule |
|---|---|
| Duplicate invoice | Same invoice ID appears more than once |
| Missing amount | Invoice has no billed amount |
| Missing meter read | No meter reading for that building, utility and month |
| Amount mismatch | Billed amount is not billed usage x rate (within $0.01) |
| Usage mismatch | Billed usage differs from the meter reading by more than 2% |
| Meter outlier | Meter reading is more than 3x the usual level for that building and utility |

On the sample data the pipeline reviews 435 invoice rows, finds 19 issues and keeps 420 clean rows for reporting. Every excluded row is listed with the reason, so nothing disappears silently.

## Summary tables (`sql/reporting_queries.sql`)

- `monthly_cost_by_utility.csv`: cost, usage and average cost per building by month
- `building_cost_summary.csv`: total and average cost, and cost per unit, by building
- `year_over_year.csv`: fiscal-year comparison (July to June)

## Run it

```bash
pip install -r requirements.txt
python src/generate_sample_data.py
python src/validate_and_report.py
```
